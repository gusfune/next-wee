# Next Wee

A tentative of an unopinionated version of a Ruby on Rails inspired CLI for NextJS.

Why?

Saves tokens instead of generating the same things over and over.

Trust me, it saves tokens and time.

## Install

```
npm install -D next-wee     # or pnpm add -D / yarn add -D / bun add -d
npx wee about
```

Node 22 or newer. Works under npm, pnpm, yarn and bun.
